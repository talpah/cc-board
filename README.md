# cc-board

Claude Code plugin: per-project kanban board via `/enable-kanban`. Work items live with
the repo instead of in a separate tool you have to remember to open.

> [!IMPORTANT]
> **Archived — an experiment that did not stick.**
>
> It worked, but I did not end up liking it in practice, so it is archived rather
> than maintained. The code stays up for anyone who wants to look at it.
